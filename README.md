# Nuven — Landing Page

Web platform for **Nuven**, built with **Next.js**, **TypeScript**, **Tailwind CSS**, **GSAP**, and **Radix UI**, featuring optimized granular image delivery and Cloudflare Turnstile form protection.

🔗 **Live Demo:** [nuven-landing.vercel.app](https://nuven-landing.vercel.app)

## Tech Stack

- **Framework:** Next.js (App Router), React, TypeScript
- **UI & Motion:** Tailwind CSS, Radix UI, GSAP, Lucide Icons
- **Security & Media:** Cloudflare Turnstile, `next-granular-images`
- **Tooling & Infra:** Bun, ESLint, Prettier, Husky, Commitlint, Docker

## Local Development

```bash
bun install
bun dev
```
